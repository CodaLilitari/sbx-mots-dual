SBX MOTS DUAL SABERS - SPECIAL EDITION v1.2.0
26 October 2026

Requires your normal owned Mysteries of the Sith installation.
No separate SBX 3.0/3.1 installation or engine patch is required.

1. Create a fresh empty expansions\SBX-Dual folder in your MotS directory.
2. Choose ONE download:
   SBX-MotS-Dual-Special-Edition.zip for the accelerated renderer; or
   SBX-MotS-Dual-Special-Edition-Software.zip for the software renderer.
   Copy the selected ZIP's root SBX-MotS-Dual.goo into that mod folder.
   These are complete alternatives. Do not load both together.
3. Run from the MotS game directory:
   JKM.EXE -path expansions/SBX-Dual

Keep older mod folders separately. Do not copy older SBX archives or loose
overlays into this fresh folder. Run without -path to play without the mod.

Equip the Sith saber and use the existing Lightsaber Stance action:
staff -> Sariss -> dual/Boc -> reverse grip -> staff.
Third person shows both separate blades; first person keeps the staff model.
Reverse-grip alternate fire hops/spins. Running flat out enters a dash pose.

Extinguish the saber before saving. Turn it off/on if a loaded saber loses damage.

Validation and limitations are included below in the game ZIP's README.
Full source reports are in the Builder ZIP and project repository.
Full credits are at docs/CREDITS.md in this game ZIP. Original documents under
docs/original are retained to honor source-package terms; keep them with any
redistribution. The game loads only the GOO.
