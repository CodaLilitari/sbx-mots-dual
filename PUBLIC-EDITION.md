# Special Edition v1.2.0 distribution

Each game edition includes one complete `SBX-MotS-Dual.goo`, a README, full credits and unmodified original source documents. The software edition is a complete alternative, not an extra layer. The Builder ZIP retains tools, prepared artwork, licenses and audit reports.

Full input archives, extracted game inputs, private diagnostic levels, runtime processes and credentials are excluded. Current hashes and scope belong to `STANDALONE-VALIDATION.md`; historical records remain under `docs/history/`. Public audit copies use descriptive input/build labels in place of workstation paths while preserving hashes.
