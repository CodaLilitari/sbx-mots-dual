# Public documentation edition

Prepared on 2026-10-23 for Coda (Codex Lily) and Andrei's authorized public release. This edition changes release documentation, public audit path references and package manifests. It does not change any tested game resource, builder tool/vendor file, original source readme, license or curated screenshot.

The main overlay still requires a separately obtained SBX-MotS v3.0 base and the user's own MotS installation. The optional software texture layer installs after it. The builder takes its documented explicit local inputs. The complete base mod, retail archives, source extraction tree and private runtime fixtures are not included.

Original build/runtime receipts remain historical evidence, including their original generation-stage status and candidate identities. In public audit copies, `project-artifacts/`, `local-workspace/` and `local-game-inputs/` are logical provenance labels, not included directories or downloadable paths. References to raw private fixtures are retained as provenance and explicitly do not mean that those fixtures are supplied. The five screenshots in `docs/evidence/` are the curated original-executable captures; the palette comparison in `docs/audit/` is an offline calculation.

The separately supplied `public-edition-receipt.json` and `SHA256SUMS.txt` identify all three public ZIPs and prove equality with the tested originals: 602 main game files, 193 optional MAT files and 20 builder tool/vendor files. Each ZIP's `PACKAGE-MANIFEST.json` hashes its public members. Packaging does not add gameplay validation. Browser compatibility is expected from source inspection, not a completed browser run; multiplayer, full campaign and save/load coverage remain unverified.

Since this edition, v1.1.0 has replaced `docs/original/sbx dual sabers readme.txt` with Dual Sabers 17's readme (hashes in `docs/original/SOURCE-DOCUMENT-HASHES.json`) and added four screenshots, `docs/evidence/openjkdf2-mots-reverse-grip-*.png`, taken in OpenJKDF2's MotS mode, not the original executable (see `SCREENSHOT-PROVENANCE.json`).

See `RELEASE-NOTES.md`, `CREDITS.md` and `RETAIL-VALIDATION.md`. The original source readmes and OpenJKDF2 license remain unmodified under `docs/original/` and `docs/licenses/`.
