# SBX MotS Dual Sabers — Special Edition v1.2.0

The finished GOO includes the SBX-MotS base and all converted resources. Play with an ordinary owned MotS installation; no separate SBX 3.0/3.1 installation or engine patch is required. Choose one complete accelerated or software edition and follow `INSTALL.txt`.

This release retains the verified v17 merge, including reverse grip through native animation keys, directional attacks, hop/spin, dash pose, retimed attacks and footstep markers. Original JKM tests exercised reverse grip, attack input, native damage and dash entry/exit. Full campaign, multiplayer, exhaustive skins, audible sound and save/load coverage remain limited as documented.

The inherited title screen gains a small Special Edition subtitle. Its original palette, button regions, duel illustration and logo pixels are preserved; only the right title block changes. Gameplay resources are byte-identical to the tested standalone build. A source-based actor voice fallback reuses the already bundled original JK response.

Each game ZIP includes one GOO and README plus original credits/documents retained to honor source-package terms. The Builder ZIP contains reproducible tools, prepared artwork, provenance and validation. No retail executable or complete retail archive is included.
